# 定方向：先定方向，再写代码

决定片子好不好看的，是写代码之前的设计：讲什么、什么气质、每个镜头的主角、字多大、界面放大几倍。把这些写进方向文件（引擎 A 的 `DIRECTION.md` / 引擎 B 的 `src/spec.ts` 契约）再动手。

> 来源：融合 guizang 的 `direction.md`（产品气质、三方向、专属手法、画面规范、镜头表）与 motion-design 的 Stage 2（风格合成法）。两引擎通用；引擎专属细节回各自说明书。

## 1. 读目标

- **产品（引擎 A）**：仓库审计 + 用户输入，确定功能、发布状态、设计语言、暗色主题、母题候选。
- **提示词/主题（引擎 B）**：三本账——Spec 账（每条值/指令逐字）、Transformation 账（每个"变成"动词）、Element 账（每个被画的东西 + playbook）。长提示词末三分之一与开头同权重。

## 2. 拆参考（给了参考视频/图片时）

抽帧看全片 → 逐条列手法（是什么/表达什么/出现在哪段/多久）→ 学"做法"不抄"样子"。参考片的颜色/图形/字体属于它的品牌，写清本片是否采用、改写成什么、依据。

## 3. 提炼气质与母题

- 谁在用、什么情境、什么感觉（冷静/轻快/温暖/硬核/安静…）。
- 设计语言：色板/字体/圆角/阴影/明暗主题（有暗色主题当候选）、图标风格，来源写到文件路径。
- 母题候选：标志几何、核心界面本身、产品处理的数据形态、领域隐喻（写作→纸墨、音乐→波形、财务→走势线）、产品名字的字面意象。

## 4. 提出 2–3 个方向，沿不同轴拉开

每个方向在下表每轴各选一，彼此至少在三个轴上不同，各自内部自洽：

| 轴 | 可选取向（举例） |
|---|---|
| 底色与光 | 黑舞台+发光；纸白+墨线；品牌色块；明暗交替；真实照片感 |
| 字体声音 | 超细大字；粗重冲击；衬线编辑；等宽技术；圆润亲和 |
| 母题来源 | 标志几何；界面本身；数据形态；领域隐喻；用户场景 |
| 镜头语言 | 平面排版；3D 舞台；微距特写；一镜到底；录屏质感 |
| 转场词汇 | 硬切卡拍；穿越缩放；遮罩擦除；形状变形；匹配剪辑 |
| 节奏 | 发布会从容；预告片紧凑；轻快俏皮；安静叙事 |
| 声音 | 电子脉冲；钢琴弦乐；打击乐；氛围铺底；用户曲子 |

按气质/受众/平台选一个，写理由。用户想看方向时，给 2–3 个方向 + 关键静帧等反馈。

## 5. 风格合成（motion-design 方法，两引擎通用）

把"感觉"翻译成"世界 → 能量 → 具体值"：

1. **主题 → 世界**：这个主题活在什么材质世界（纸/墨/玻璃/金属/织物/屏幕/自然/城市/实验室）？选一个，至多一个对立的"转化世界"。
2. **受众与情绪 → 能量**：冷静或冲击、温暖或精确、俏皮或严肃 → 定 tempo/easing/overshoot/密度。
3. **写成具体值**（→ `design-contract.md`）：palette hex+角色、type 家族字重字号字距、marks SVG 手法、texture-light 逐元素、composition 占位留白边距、motion 每类移动的 easing、transition 语法、signature details、sound palette、bans。

## 6. 本片专属手法（3–5 个）

每个手法必须能写成"因为产品/主题有 X，所以用 Y"。写不出 X 就删。

| 有什么 | 可长成什么 |
|---|---|
| 点阵标志 | 粒子汇聚落进点阵每一格 |
| 接入很多服务 | 成员沿倾斜环绕转 |
| 面向开发者、以代码为材料 | 产品自己的代码组成的字符场 |
| 笔记/写作 | 字逐笔写出、纸纹、墨晕 |
| 数据分析 | 真实图表路径逐段画出、数字滚动落定 |
| 设计工具 | 构造线、控制点、网格吸附 |
| 协作产品 | 多光标同时进入、状态实时合并 |

## 7. 反重复

- **跨片**：动手前看同工作区上一支片子的方向文件与联系表，新片至少在三个轴上不同，不复用开场/章节/背景手法。
- **片内**：不所有元素同一种入场；相邻镜头换取景或明暗；同一种转场不连用三次。
- **案例不是模板**：某个产品的推导属于那一次，别照搬到另一个。

## 8. 叙事结构（按内容选）

默认"钩子 → 品牌 → 功能证明 ×3–5 → 小功能快切 → 收尾"只是其一。也可：问题→转折→解决；完整做完一件真实任务；一镜到底穿行；前后对比；倒数清单；一天的使用。

## 9. 画面规范（frame design system）

写成具体数字：画幅/帧率/底色/安全区（重要内容避开底部约 13%）；字号阶梯（主/次/说明，中英文各给字号字重）；界面上镜倍数（成片正文 ≥ 22px @1080p，倍数 ≈ 22 ÷ 产品正文像素）；明暗主题；动效语法（入场方式、缓动族、时长范围、本片不用什么）。

## 10. 镜头表

每镜头：时间、主角（只有一个）、画面与动作（带子拍时间）、上屏文案、声音。一个镜头至少一次状态变化或镜头运动；>2.5 秒完全不动只能是在读字。写完镜头表再搭镜头，每搭完一个出静帧对照。
