# 反 slop + 四道击穿门

防止"模板化/占位/空泛"的硬约束与自查清单。

> 来源：融合 guizang 的"不套模板"+ motion-design 的反 slop 清单 + 调研的四道击穿门。

## 反 slop 清单（逐条自查）

禁：

- 未经请求的渐变、发光（bloom/霓虹光晕/lens flare）、通用淡入、违禁回弹、粒子爆发、镜头抖动、RGB split
- 居中标题压卡片式模板布局、库存图标/emoji、占位文案、任何"看起来像模板"的东西
- 所有元素同一种入场、同一种转场

允许：把有动机的光画成形状（锥形光、窗光、反射）。

## 可溯源检查

- 每个视觉手法 → 产品/主题的哪一点？说不出的删。
- 案例/种子/fx-lab 是推导示范，不是风格包；改写后再用，不原样复用。

## 四道击穿门（选引擎/依赖时的硬门）

1. **离线无头 CLI**：无头产出 1920×1080@30fps h264（yuv420p、CRF18、AAC）
2. **中文文本**：高质量渲染 + 跨机可复现
3. **许可**：可接受（AGPL/BSL/非商用须警觉）
4. **维护**：活跃可托付（push 脉搏 + 发版节奏）

任一不过 → 出局或降级为记录性参考。
