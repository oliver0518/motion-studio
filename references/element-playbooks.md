# 元素 playbook

每个元素按它的类型设计好，再动起来。这是 motion-design 的强项，用来补 guizang 的"界面元素设计"。

> 来源：motion-design 的元素 playbook 表（Type/Object/Character/Environment/Data/UI/Transition/Texture-light/Sound）。完整实现见 `engine-remotion.md`。

| 元素 | 设计它 | 动它 | 常见失败 |
|---|---|---|---|
| **Type 文字** | 单一家族、字重字号分层、大字一行贴合声明宽度、CJK 可竖排 | EASE.out 入场，错峰 0.02–0.06s，读完再退场 | 词粘连、孤行、字幕过小、payoff 不是最重字重 |
| **Object 物件** | 真实物 ≥3 个结构特征、一个暗面、统一描线、一次建成函数 | 从物性动：纸折、液涟漪、金属绕轴转 | 符号代替实物、零件漂浮、镜头间比例不一致 |
| **Character 角色** | 先出设计稿：剪影/比例/色/脸/标记，命名姿势 | `poseMix` 姿势间过渡、`walk()`、道具挂 `grip()` | 镜头间漂移、手没扶道具、肢体穿头、火柴人默认 |
| **Environment 环境** | 从后到前分层：墙/远/中/地/前景；光来源与光形 | 常驻环境生命（天气/灯/小循环），相机不动 | 平背景、天气穿模、缺光逻辑、满屏堆 |
| **Data 数据** | 先轴与单位、值精确、标签贴标记、一图一场景 | 轴→数据→注释；计数器随标记滚；图表经共享槽 morph | 数字错、轴无标签、装饰压数据 |
| **UI / 产品界面** | 真屏或高保真重建，矩形干净、比例真实、层级真实 | 光标/状态驱动变化；推近到变化区域 | 拉伸截图、假噪点、小字不可读 |
| **Transition 转场** | 物理机制：morph/merge/遮罩/材质变/unfold/共享形匹配 | 硬边、卡拍、源头消失目标成形 | 交叉淡化、无依据硬切、身份丢失 |
| **Texture-light** | 纸墨分层、半调/排线、光画成形状 | 种子稳定或固定步进 | 全员同纹、装饰发光、未种子噪声闪烁 |
| **Sound 声音** | `cues.json`：有音高 bed+figure 或 ambience bed | 对齐 T 块；循环尾折回首 | 漏音、噪声当音乐、击点脱拍 |

## 通用规则

1. **变化是真实的**：每个 transformation 同一对象逐点 morph（等点数），源头消失、目标完全成形，不靠叠化/缩放整帧造假。
2. **身份持续**：元素颜色/形状/槽位跨场景跨材质不变；互相转化的元素共享槽常量。
3. **物理与深度显式**：每场景 back-to-front 层序；天气尊重遮挡；反射镜像；接触点计算（脚着地、手扶物）。
4. **空间词=坐标**：1920×1080 中心 (960,540)，左右三分 x≈640/1280，上 y≈360，下 y≈760。
5. **能量均匀**：变化随 tempo，峰是计划好的击点，无死秒。
