# 审片：边做边看，最后看成片

自动检查只能证明结构与文件一致；好不好看要看画面、好不好听听声音。本页是共享 criteria + 各引擎工具。

> 来源：融合 guizang 的审片三节点 + 常见问题表 + motion-design 的 Design Jury。

## 三节点（两引擎通用）

1. **每搭完一个镜头**：出静帧对照镜头表——主角一眼可见？字号够？撞没撞？
2. **全片首次导出后**：2fps 联系表看节奏构图；10fps 条带看每个转场；信息密镜头截全尺寸帧。
3. **修改后**：只重看改过的镜头 + 前后转场，最后整体过一遍。

## Design Jury（引擎 B，五评审 1–10 分，≥8 才算过）

1. **SPEC**：每个 S/X/E 行都实现且值精确（此分封顶总分）
2. **CONTINUITY**：每个 transformation 真 morph 到目标、身份/槽位持续、物理深度正确
3. **RHYTHM & SOUND**：拍点/缓动对齐契约、能量均匀、循环缝干净
4. **DESIGN**：hero 帧匹配构图、每个元素过 playbook、look 为本片设计
5. **CRAFT**：texture-light 逐元素、确定性、无 ban list

每轮修最差的一个，最多三轮。

## 引擎 A 常见问题

| 现象 | 原因 | 改法 |
|---|---|---|
| 标题与界面相撞、字挤角落 | 无字号阶梯/安全区，标题列太窄 | 回画面规范，固定标题列宽+字号，缩短文案别缩字号 |
| 中文末字/标点单独掉行 | 宽度刚好超出 | 改短一两字或微调列宽，别靠 nowrap 溢出 |
| 界面上镜字小、面板大片空白 | 按桌面尺寸上镜 | 放大根节点、面板贴内容、收空白 |
| 推近落点偏 | 3D 倾斜下手算 | 用 `screenCenterAt` 实测 |
| 浅切深中间一片灰 | 长交叉淡化 | 硬切，或主角先模糊退场再切 |
| 弹层错乱 | portal 挂 body + 打开时旋转 | portal 指到镜头内、打开期间不旋转 |
| 某段 3s+ 不动 | 末动作后无后续 | 加缓慢推近或缩短镜头 |
| 所有元素同入场 | 只用一个 reveal | 主角/辅助/背景分别设计出场 |
| 第一帧空白 | 空画面入场 | 前 5–10 帧放完成态当海报帧再淡出 |
| 每支片子都一样 | 复用案例 | 回方向文件重新推导 |

## 指标只是提示

`check_delivery.py`/`npm run check` 报的静止帧比例、硬切次数、运动曲线是"去某段看看"的提示，不是"达标=好看"。别为数字加无意义晃动。

## 声音

能试听就逐段听（sfx 分轨 → master → 编码后 MP4）；不能试听就如实说明，用频谱图 + 每秒响度检查冲击点/停顿/渐强/收尾落点。
